# AI Usage

## Tool Used

ChatGPT (OpenAI)

## How It Was Used

I used ChatGPT as a development and review assistant during this assignment. AI assistance was mainly used to:

* Discuss architecture and technology choices.
* Review transaction, idempotency, and concurrency strategies.
* Assist with unit and integration test scenarios.
* Identify edge cases and review implementation decisions.
* Assist with technical documentation.

I followed an iterative approach: suggestions were reviewed, implemented incrementally, and validated through compilation, unit tests, PostgreSQL concurrency tests, and manual API/database testing.

I use a similar AI-assisted development workflow professionally, where tools such as OpenCode help accelerate tasks such as exploring unfamiliar code, evaluating implementation approaches, and creating initial unit-test coverage.

The development conversation/transcript can be provided as required.
