## AI Assistance — Prompt Transcript

I used ChatGPT and GitHub Copilot mainly for general development assistance, code suggestions, test-case generation, debugging, and code review. The core business logic and implementation decisions were designed and reviewed by me.

1. `Can you help me create a clean Go project structure for this assignment? I'm using Echo and PostgreSQL.`

2. `Can you suggest some test cases I should cover for the wallet transfer API, including positive and negative scenarios?`

4. `Can you review these test cases and tell me if I'm missing any important edge cases?`

5. `Can you help me write the request/response structs and Echo handler boilerplate for this API?`

8. `Can you help me write the SQL query for this repository function based on the existing table structure?`

9. `Can you review this function for readability and idiomatic Go improvements without changing the business logic?`

10. `Can you suggest integration test scenarios for this API?`

11. `Can you help me improve the error responses and input validation in this Echo handler?`

12. `Can you review the completed code against the assignment requirements and point out anything I may have missed?`

### GitHub Copilot usage

GitHub Copilot was used primarily for code completion and general implementation assistance, including:

- Generating boilerplate Go code.
- Completing repository and handler functions.
- Suggesting SQL queries based on the existing implementation.
- Generating test-case scaffolding.
- Adding error handling and validation boilerplate.
- Suggesting small refactoring and readability improvements.
- Assisting with debugging compiler and test errors.

### Human involvement

The core business requirements, transaction flow, data consistency approach, and implementation decisions were determined by me. AI tools were used as development assistance rather than as the source of the core solution. I reviewed and modified the suggested code and verified the implementation through testing before submission.
