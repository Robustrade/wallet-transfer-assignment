# AI Use Disclosure

## Tool

GitHub Copilot in Visual Studio Code.

## How it was used

Copilot was used as an interactive coding assistant to interpret the assignment, propose and document a transactional design, draft implementation and behavioral tests, and diagnose test failures. The implementation was checked against the assignment and exercised with Go tests; the submitter should review and be prepared to explain every design and code decision.

## Prompts used in this session

1. "We haven the assignment to perforn, now go through assignment.md file understand the problem and tell me what you understood"
2. "start implementing as per given instruction in assignment.md"

The conversation was iterative: repository inspection, the design note, tests, implementation, and validation followed those requests. The complete conversation transcript can be supplied from the GitHub Copilot Chat session if requested; the prompts above are included here as the assignment's fallback disclosure.
