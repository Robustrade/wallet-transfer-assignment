# AI usage

## Tool

Cursor (agent session with Grok 4.6).

## How it was used

The assignment was read first. A design note was written before code. Implementation and tests followed that design. The human directed the workflow (design note, then service and tests) rather than asking the model to invent the submission process.

Prompts in this session:

1. Check the ASSIGNMENT.md file and read what you need to do.
2. I want you to write a design note first, then implement the service and tests.

A full Cursor transcript for this session can be exported from the editor (agent transcripts under the local Cursor project). If a file export is attached to the PR, that is the canonical record.
